The blueprint system

Every token, both faces and every control in the product, on one page. Nothing here is decoration: if a pattern is not on this page it does not exist, and if it is on this page it is keyboard-operable and announced.

Reference · not a product screen

Panel

The frame every surface in the product uses: a hairline box with a registration mark centred on each corner, 6px of each crosshair falling outside the border. The marks are pseudo-elements, so a panel costs no extra markup — but an ancestor with overflow: hidden will clip them.
